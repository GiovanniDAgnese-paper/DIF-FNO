# Manuscript: *The D'Agnese Chart Operator*

`dagnese-chart-operator.tex` is a self-contained article (no class files beyond
standard LaTeX) with the full proofs, the deterministic verification tables and
the paired-seed benchmark.

## Build

```bash
cd paper
pdflatex dagnese-chart-operator
bibtex   dagnese-chart-operator
pdflatex dagnese-chart-operator
pdflatex dagnese-chart-operator
```

or `latexmk -pdf dagnese-chart-operator.tex`.  Requirements: a standard
TeX Live / MacTeX installation (`amsmath`, `amsthm`, `booktabs`, `algorithm`,
`cleveref`, `hyperref`, `lmodern`).

The figures are included from `../figures/study/` and `../figures/paper/`; both
are generated by the repository:

```bash
python scripts/run_chart_study.py        # figures/study/*
python scripts/make_paper_table.py       # paper/tables/benchmark.tex + figures/paper/*
```

`paper/tables/benchmark.tex` is **generated** — do not edit it by hand.  It is
produced from `results/v2/*.json`, and `results/v2/TABLE.md` is produced from
the same data, so the table in the paper and the table in the repository cannot
drift apart.

## Provenance of every number

| table / figure | script | data |
|---|---|---|
| `tab:certificate`, `fig:certificate` | `scripts/run_chart_study.py` | `results/study/STUDY.json` |
| `tab:roundtrip`, `fig:roundtrip` | same | same |
| `tab:eq`, `fig:learned` | same | same |
| `tab:benchmark` | `scripts/make_paper_table.py` | `results/v2/*.json` |

The deterministic study involves no training, no seeds and no sampling; it runs
in under a minute and its output is bit-reproducible on the same machine.

## Status

The manuscript is a preprint draft.  It has been syntax-checked (balanced
environments, all `\cite` keys present in `references.bib`, all `\ref`/`\cref`
targets defined) but not compiled to PDF in the environment where it was
written, because TeX was not installed there.  Please build it before
submission.
