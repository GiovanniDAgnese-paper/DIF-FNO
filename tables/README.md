# Tables

## `final_benchmark.tex`

The table as published with the v4 code: **Standard FNO** vs **DIF-FNO v4** on
the three original domains (Star, L-Shape, Annulus), 60 epochs, 80/20 split.

It is kept for provenance of the paper artefact; it is **not** regenerated by
this repository. The numbers come from `results/FINAL_CONSOLIDATED.json` (runs
`results/real_*_v3/v4*.json`), produced by the `v4` pipeline preserved as
`scripts/generate_real_data.py` / `scripts/train_real_v4.py`. Those datasets are
no longer distributed and the runs are not bitwise reproducible (see
`README.md` §5.2).

Note the two conventions that differ from the regenerated tables:

| | published v4 | this repository |
|---|---|---|
| MSE normalisation | over the whole bounding box | over the active (masked) cells |
| `det J` scaling | raw finite differences | divided by the local spacing, so `det J(Id) = 1` |
| barrier `tau` | `0.005` in index units | `0.05` in physical units (`tau / h^2` was `4.96`) |

## Regenerated tables

Everything quoted in the README is generated from `results/repro/`:

```bash
python scripts/run_benchmark.py --consolidate-only --out results/repro
```

which writes `results/repro/CONSOLIDATED.json` (all runs, paired tests),
`results/repro/table.md` and `results/repro/table.tex` (the LaTeX tables used in
the paper draft, including the paired-difference panel).
