# DIF-FNO: Diffeomorphic Fourier Neural Operators

[![Zenodo](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.22071926-blue)](https://doi.org/10.5281/zenodo.22071926)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

DIF-FNO (Diffeomorphic Fourier Neural Operator) extends classical neural operators to complex non-convex domains via implicit diffeomorphic mapping and Jacobian barrier regularization.

## Key Features
- **Grid Folding Elimination:** Uses Jacobian barrier loss to ensure valid transformations across complex geometries (Star, L-Shape, Annulus).
- **High Benchmarking Accuracy:** Superior relative $L^2$ and $H^1$ errors compared to Geo-FNO baselines.
